# 拾光 · 校园失物招领系统

拾光是一个面向校园场景的失物招领前端原型，覆盖物品发现、信息发布、认领申请、审核管理、公告管理和数据总览等核心流程。项目使用 **Vue 3 + Vite + TypeScript + Pinia + Vue Router + Element Plus** 构建，当前通过 Pinia 内存 Mock 数据演示完整业务闭环，并实现了基于路由守卫的前端 RBAC 权限控制。

## 技术栈

- **Vue 3**：`<script setup>` + Composition API
- **Vite**：开发服务器与生产构建
- **TypeScript**：领域类型与类型安全，`vue-tsc --noEmit` 类型检查
- **Pinia**：集中式状态管理（角色、认证、物品、认领、公告、评论）
- **Vue Router**：路由元信息、登录守卫与角色访问控制（RBAC）
- **Element Plus**：表单、表格、弹窗、上传、分页等 UI 组件
- **ECharts**：已加入依赖，用于后续数据大屏可视化

## 功能清单

### 学生端

- **物品发现（首页）**：物品卡片列表，支持关键词模糊搜索（名称/地点/标签）、类型（全部/寻物/招领）、分类、地点、时间（近 3/7/30 天）多维筛选，支持分页。
- **详情弹窗**：图片轮播、物品标签、描述、统计信息（浏览/点赞/收藏），评论区支持发表评论、楼中楼回复、点赞，点赞收藏逻辑即时反馈。
- **申请认领**：仅对「招领中」「待认领」状态物品开放，需填写认领说明并可上传证明材料图片。
- **信息发布**：
  - 物品类型（丢失/拾取）+ 物品名称 + 联系方式；
  - **多标签多选**（数码/证件/日用/服饰/书籍/其他）；
  - **动态地点联动选择器**：根据所选建筑类型（宿舍楼/教学楼/食堂/桥边操场）动态展示不同的输入项，并自动拼接完整地址；
  - **图片上传**：仅图片格式、最多 3 张、本地预览与删除。
- **我的发布 / 我的认领**：查看当前用户发布的记录与提交的认领申请及审核状态。
- 表单校验：物品名称、标签、地点、联系方式、详细描述、图片数量均有前端校验与错误提示。

### 失物招领管理员端

- **审核中心**：查看待审核信息，支持搜索/筛选/分页，可「通过审核」或「驳回」（驳回需填写原因）。
- **物品管理**：全部物品表格，支持搜索与状态筛选，可对物品「编辑」「下架/上架」「删除」（删除/下架带二次确认）。

### 系统管理员端

- **数据总览**：指标卡（累计发布/成功归还/待处理/归还率）、近 30 日趋势图、高频地点排名（当前为 CSS 占位图表）。
- **账号管理**：校园账号列表与角色。
- **公告管理**：公告列表与编辑入口（占位）。

## 启动项目

环境要求：Node.js 18+，npm 9+。

```bash
# 进入项目目录
cd lost-and-found

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

浏览器打开终端输出的本地地址即可。其他常用命令：

```bash
# TypeScript 类型检查
npm run type-check

# 生产构建
npm run build

# 预览生产构建结果
npm run preview
```

## 演示账号

登录页支持选择以下三种演示身份。当前登录仅校验账号和密码非空（预填的 `2023010218 / 123456` 可直接登录），并写入本地 Mock Token，不连接真实后端。

| 角色 | 演示账号 | 密码 | 可见菜单 | 主要能力 |
| --- | --- | --- | --- | --- |
| 普通学生 | 任意非空（如 `2023010218`） | 任意（如 `123456`） | 发现物品、发布信息、我的发布、我的认领 | 搜索、发布、详情查看、点赞收藏评论、申请认领 |
| 失物招领管理员 | 任意非空 | 任意 | 审核中心、物品管理 | 审核发布、维护物品状态（编辑/下架/删除） |
| 系统管理员 | 任意非空 | 任意 | 数据总览、账号管理、公告管理 | 查看统计数据、管理账号和公告 |

> 三种角色均可使用「任意非空账号 + 密码」登录；登录页下拉选择对应身份即可体验对应工作台。

## 权限与路由

- 登录后才能访问 `/app` 下受保护的工作台；未登录访问时会跳转到 `/login?redirect=<原地址>`。
- 各路由通过 `meta.roles` 声明允许角色，菜单通过 `src/navigation.ts` 按角色过滤；即便直接输入地址，路由守卫也会拦截越权访问并返回当前角色首页。
- 只做前端 RBAC 仅用于体验，真实后端仍需二次校验（Token、身份、数据操作权限）。
